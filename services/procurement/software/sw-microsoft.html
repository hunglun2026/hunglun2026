微軟軟體

Microsoft 各項產品授權，含 Dynamics 365 與伺服器端授權。

Microsoft 的各類產品授權。同一產品常有依使用者、依裝置、依核心數等不同計價方式，且訂閱與永久授權的長期成本差異大，建議以三到五年為期比較。

適合這樣用

  • 作業系統授權：新購與既有電腦的 Windows 授權。
  • 桌面應用：Office 桌面版，特別是需要離線或進階功能的行政作業。
  • 伺服器授權：校內自建伺服器的作業系統與存取授權。

採購前先確認

  • 教育授權的資格與續約：教育方案的資格條件與續約規則要先確認，別等到期才發現不適用。
  • 隨機授權還是大量授權：隨機授權綁機器，機器汰換後不能移轉。
  • 會不會重複付費：已導入雲端方案的學校，部分授權可能已含在內。
