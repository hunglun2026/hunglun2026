ChromeOS Flex 舊電腦升級服務：比買新機便宜的延壽方案

學校或公司裡那些跑得越來越慢、快被淘汰的舊電腦，不用整批換新機，改裝成跟 Chromebook 一樣的「ChromeOS Flex」系統，加上管理授權，就能繼續正常上課、辦公——是採購全新 Chromebook 之外，成本較低的一個選項。這是需要付費的服務（評估、安裝、授權都算在內），不是免費升級。

簡單說：您現在用的電腦如果是 Windows 或 Mac，開機越來越慢、常常當機，但硬體其實還堪用，ChromeOS Flex 就是幫這台電腦「換腦袋」——洗掉原本的系統，改灌上跟 Chromebook 一模一樣的系統，讓它變年輕。跟直接買全新 Chromebook不同，這個做法不用編列購買新硬體的預算，改成負擔安裝服務與管理授權的費用，比整批換新機便宜，適合手上還有一批堪用舊電腦、想先撐過這一兩年再談汰換的學校或公司。

這套系統長什麼樣子

  • 作業系統本身是 Google 免費提供的：ChromeOS Flex 這套系統不用另外付軟體授權費，用隨身碟灌到舊電腦裡，取代原本的 Windows 或 macOS；但整套服務仍需要付費，詳見下方「管理授權」說明。
  • 開機變快、幾乎不用維護：跟 Chromebook 用的是同一套系統，開機通常只要幾秒鐘，系統會自動更新，不太需要 IT 人員三不五時跑去修。
  • 東西存在雲端，不怕電腦壞掉：文件、資料主要存在雲端（跟用 Google 文件、雲端硬碟一樣），就算這台電腦硬碟壞了或不見了，換一台登入同一個帳號，東西馬上都在，不用擔心資料跟著電腦一起消失。
  • 它終究是舊電腦，體驗有極限：畢竟硬體是舊的，跑起來不會像全新 Chromebook 那樣快，也沒有 Chromebook 特別加強的防摔耐用設計。這是幫舊電腦「延壽」，不是把它變成新機，長期還是建議規劃換新。

動手前要先確認的三件事

  • 先確認電腦型號裝得起來：不是每一台舊電腦都適合，Google 有公布一份「測試過沒問題」的官方機型清單，可以先用電腦的品牌型號查一下自己手上那台的認證狀態（開啟 Google 官方認證機型清單 ↗）。我們也會另外挑幾台代表性的機器實際裝裝看，確定觸控螢幕、鏡頭、Wi-Fi 這些周邊都正常運作，再決定要不要全部一起換。
  • 資料一定要先備份：安裝這套系統，等於把整台電腦的硬碟重新格式化，原本 Windows 或 Mac 裡的所有資料都會不見，動手前一定要先備份重要檔案。也可以先用隨身碟開機試用看看，這個階段完全不會動到原本硬碟裡的東西，可以放心先體驗。
  • 分批安裝比較不累人：電腦教室、圖書館的公用電腦、行政室的備用機，可以先從其中一批開始換，不用一次全部動工，人力負擔會小很多。

還需要另外買一個「管理授權」（CEU）

  • Chrome Education Upgrade（CEU）是什麼：您可以把它想成是「電腦教室的遙控器」。裝了這套系統的電腦，如果沒有搭配 CEU，就只是一台台各自獨立的電腦，IT 人員要一台一台去設定。有了 CEU，就能坐在辦公室裡，透過一個管理畫面，同時幫全校（或全公司）的電腦統一設定要開放哪些網站、裝哪些軟體、誰可以用什麼功能，跟管理一般 Chromebook 完全是同一套做法，不用另外學新工具。

常見問題

ChromeOS Flex 跟直接買 Chromebook 有什麼不一樣？
最大差別是「錢」跟「新舊」。ChromeOS Flex 是用學校或公司既有的舊電腦重新灌一套系統，不用花錢買新機；但畢竟硬體是舊的，不會像全新 Chromebook 那樣快、也沒有耐摔、防潑水這類特別加強的設計。簡單說：這是先撐過這一兩年的過渡方案，不是永久取代新機採購。
改裝後也要另外買管理授權（CEU）嗎？
要。改裝完的電腦如果沒有搭配 CEU，就是一台台獨立的電腦，IT 人員得一台一台跑去設定。有了 CEU，就能在一個畫面上同時管理全校或全公司所有電腦（要開哪些網站、裝哪些軟體、誰能用什麼功能），跟平常管理 Chromebook 的方式完全一樣，不用重新學。
哪些舊電腦可以改裝？
Google 有公布一份「測試過沒問題」的官方機型清單（開啟 Google 官方認證機型清單 ↗），大部分 2010 年之後買的、規格還堪用的 Windows 電腦或 Mac 都在清單內或可以試試看。但每台電腦的觸控螢幕、鏡頭這些配件相容性不一定一樣，建議先挑幾台代表性的機器實際裝裝看，確認沒問題再決定要不要全部一起換。
會不會把電腦裡的資料洗掉？可以先試用再決定嗎？
安裝這套系統，等於把整台電腦重新格式化，原本 Windows 或 Mac 裡的系統跟所有檔案都會消失，動手前一定要先備份重要資料。不過也可以先用隨身碟開機，用「試用模式」實際操作看看效果如何，這個階段完全不會動到電腦原本硬碟裡的東西，確認滿意了再正式安裝也不遲。
適合哪些學校或公司？
預算有限、但手上還有一批堪用舊電腦、想先撐過這段汰換空窗期的單位最適合，像是電腦教室、圖書館的公用電腦、行政室的備用機都很常見這樣做。如果是長期要用的主力設備，還是建議規劃直接換成全新 Chromebook，體驗跟管理彈性都會更完整。
