ChromeOS Flex 舊電腦升級與 CEU 授權導入

既有 Windows／Mac 電腦免換機改裝為 ChromeOS，搭配載具管理授權（CEU）統一納管，延長老舊電腦壽命的低成本方案。

跟採購全新 Chromebook不同，ChromeOS Flex 是 Google 提供的免費作業系統，直接把學校手上既有的 Windows 或 Mac 電腦改裝成 ChromeOS，不用編列新機採購預算。適合預算有限、但手上還有一批堪用舊電腦想先撐過汰換空窗期的學校。

ChromeOS Flex 是什麼

  • 免費作業系統：由 Google 提供，透過隨身碟安裝到既有電腦上，取代原本的 Windows 或 macOS。
  • 開機快、好維護：沿用 ChromeOS 架構，開機速度與自動更新機制與一般 Chromebook 相同。
  • 雲端優先：資料與應用以雲端服務為主，硬碟毀損或裝置遺失時，換一台登入帳號就能接續使用。
  • 硬體限制：效能與周邊相容性受限於原本的電腦規格，不具備 Chromebook 專用的軍規耐用設計與內建安全晶片，屬於過渡方案而非長期取代。

導入前的評估

  • 機型相容性確認：先對照 Google 公布的認證合格機型清單，並挑幾台代表性機型實機安裝測試，確認觸控、攝影機、無線網卡等周邊都正常運作再全面鋪開。
  • 資料備份：安裝會清空整台電腦的硬碟，原本的 Windows 或 macOS 系統與資料都會被覆蓋，動手前務必先備份。可先用隨身碟開機以「試用模式」體驗，不會動到原本硬碟內容。
  • 數量與時程規劃：依電腦教室、圖書館共用電腦、行政備用機等場景分批安裝，降低單次導入的人力負擔。

載具管理授權

  • Chrome Education Upgrade（CEU）：改裝後的裝置一樣要搭配 CEU 才能納入管理主控台，統一設定政策、應用程式與使用者權限，跟一般 Chromebook 的管理方式相同。沒有 CEU 的話裝置只能各自獨立使用，無法集中控管。

常見問題

ChromeOS Flex 跟直接買 Chromebook 有什麼不一樣？
ChromeOS Flex 是把學校既有的 Windows 或 Mac 電腦改裝成 ChromeOS，不用買新機。硬體本身沒有 Chromebook 專用的快速開機、內建安全晶片與軍規耐用設計，效能與體驗會受限於舊硬體規格，適合作為過渡方案延長汰換前的可用年限，不是要取代新機採購。
改裝後也要買 CEU 才能管理嗎？
要。ChromeOS Flex 裝置一樣要搭配 Chrome Education Upgrade（CEU）才能納入管理主控台統一設定政策、應用程式與使用者權限，跟一般 Chromebook 的管理方式相同。沒有 CEU 的話裝置只能各自獨立使用，無法集中控管。
哪些舊電腦可以改裝？
Google 有公布認證合格的機型清單，多數 2010 年後出廠、規格堪用的 Windows PC 或 Mac 都在清單內或可嘗試安裝，但實際能不能穩定運作、周邊（如觸控、攝影機）相容性如何，會因原廠硬體差異而不同。導入前建議先挑幾台代表性機型做評估安裝，確認可用再全面鋪開。
資料會不會不見？可以先試用再決定嗎？
改裝過程會清空整台電腦的硬碟並安裝 ChromeOS Flex，原有的 Windows 或 Mac 系統與資料都會被覆蓋，動手前務必先備份。也可以先用隨身碟開機以「試用模式」體驗，確認可行再正式安裝，不會動到原本硬碟內容。
適合哪些學校或場景？
預算有限、但手上有一批堪用舊電腦想先撐過汰換空窗期的學校最適合；電腦教室、圖書館共用電腦、行政備用機都是常見場景。長期使用建議還是規劃汰換為正規 Chromebook，體驗與管理彈性會更完整。
