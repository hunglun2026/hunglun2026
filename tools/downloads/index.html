ChromeOS Flex 下載

Windows 電腦轉 ChromeOS Flex 的一鍵轉換整包。

⬇
下載一鍵轉換整包flex-full.zip・約 1GB・含 Google 轉換程式，解壓後不用再上網下載
  1. 下載完，在 zip 上按右鍵，選「全部解壓縮」
  2. 打開 flex 資料夾，先雙擊 一鍵轉換Flex-模擬.bat，按「是」，輸入 Y
  3. 看到「官方檢查項目完成 5/5」才可以跑 一鍵轉換Flex-正式.bat

正式版會清掉這台電腦的 Windows 和所有資料，無法復原。四個檔案要放在同一個資料夾。

1 挑電腦・2 修 WMI・3 模擬・4 正式轉換・5 卡住怎麼辦・6 改回 Windows

有還原卡的話

轉換寫進硬碟的東西一重開就會被還原掉，一定要先移除：

  • 開機時按卡的熱鍵（常見 Home 或 F10）進管理畫面，輸入管理密碼（找學校資訊組）
  • 選「移除」或「解除安裝」，關機後才拔卡。不要直接拔，硬碟可能開不了機

另外：插上電源；要留的檔案先複製出來；轉換前在「設定 → 系統 → 關於」記下 Windows 版本，以後要改回來用得到。

2修 WMI（看到「命名空間無效」或「類別無效」才需要）

WMI 是 Windows 內建的系統資訊資料庫，轉換程式靠它查硬碟和 TPM。學校電腦常因還原軟體壞掉，畫面會出現 tpm.msc「命名空間無效」，或一鍵檔停在「系統資訊資料庫（WMI）異常」。這不一定代表沒有 TPM。

  1. 開始 → 輸入 cmd → 在「命令提示字元」按右鍵 →「以系統管理員身分執行」
  2. 一行一行輸入： 
    winmgmt /verifyrepository
mofcomp %windir%\System32\wbem\storagewmi.mof
mofcomp %windir%\System32\wbem\Win32_Tpm.mof
  3. 重新開機，開 tpm.msc 看有沒有恢復
  4. 還是不行：第 2 步第一行顯示「不一致」就輸入 winmgmt /salvagerepository，顯示「一致」就輸入 winmgmt /resetrepository，再重新開機

這些指令只重建 Windows 的系統資訊，不會動到檔案。

3先跑模擬（不會動硬碟）

  1. 雙擊 一鍵轉換Flex-模擬.bat，跳出視窗按「是」
  2. 看到綠字「這次只做模擬測試」，輸入 Y 按 Enter
  3. [2/5] 應該寫「使用同資料夾的 frd-latest.zip（不用上網下載）」
  4. 最後要看到 「官方檢查項目完成 5/5」、綠字「模擬測試完成」
  5. 拍下畫面。桌面的 Flex結果-電腦名稱-時間.zip 傳給技術人員

沒有 5/5、或出現紅字 [停止]：拍下來，不要跑正式版。

4正式轉換（會清掉 Windows）

  1. 雙擊 一鍵轉換Flex-正式.bat，按「是」
  2. 確認是紅字「轉換完成後，這台電腦的 Windows 和裡面所有資料都會被清空」，輸入 Y 按 Enter。看到綠字「只做模擬」就是點錯檔，關掉重來
  3. 它會先自己再模擬一次，通過才正式轉換。看到「轉換已經開始：電腦會重新開機」，拍照
  4. 手機開始計時。約 2 分鐘內電腦會自己重開機；沒有的話手動重開一次
  5. 重開機後是 ChromeOS Flex 安裝畫面，不要按任何東西、不要斷電
  6. 停在 ChromeOS Flex 歡迎畫面就是成功，記下總共花幾分鐘
  7. 歡迎畫面選語言、連 Wi-Fi、登入 Google 帳號

轉完驗收

  • 鍵盤、滑鼠或觸控板、喇叭、鏡頭、Wi-Fi 或網路線
  • 開 Chrome 瀏覽網頁
  • 筆電另外試：闔上螢幕能睡眠和喚醒、充電與電量顯示

5卡住怎麼辦

狀況先做什麼
[停止] C 槽最多只能縮出 X GB見下方「縮不出空間怎麼辦」
[停止] 系統資訊資料庫（WMI）異常第 2 步修 WMI；有還原卡先移除
模擬沒有 5/5、卡在 TPM進 BIOS（ASUS 常見 F2 或 Del）在 Advanced 或 Security 找 PTT、TPM、Trusted Computing 打開；找不到就換一台
[停止] 不是 UEFI／不是 GPT第 1 步「開機模式」那列
[停止] 可用空間不足清理檔案、清空資源回收筒後重跑
重開機後黑畫面或停在廠商標誌超過 20 分鐘拍照記時間，進 BIOS 把 Secure Boot 關掉再開機
重開機又回到 Windows安裝程式沒開起來，Windows 還在。拍照，看 C:\deploy\agent.log 最後幾行
安裝畫面出現錯誤訊息拍下錯誤訊息全文

縮不出空間怎麼辦

FRD 要從 C 槽尾端切出約 5.4GB 放安裝程式。C 槽可用空間再多，只要尾端卡著搬不動的檔案（分頁檔、休眠檔、還原點），能縮的就不夠。2026-10-07 學校的 ASUS SD310（120GB SSD）就是這樣：可用空間超過 12GB，卻只縮得出 2.1GB，一鍵檔停在「C 槽最多只能縮出…」。

  1. 先看現在能縮多少：系統管理員 PowerShell 輸入 $p=Get-Partition -DriveLetter C; $s=Get-PartitionSupportedSize -DriveLetter C; [math]::Round(($p.Size-$s.SizeMin)/1GB,1)，顯示的數字要 6 以上（FRD 要約 5.4GB）
  2. 關休眠（系統管理員命令提示字元）：powercfg /h off
  3. 刪還原點：vssadmin delete shadows /for=C: /all /quiet
  4. 暫時不用分頁檔：設定 → 系統 → 關於 →「進階系統設定」→ 效能「設定」→「進階」→ 虛擬記憶體「變更」→ 取消「自動管理」→ 選 C 槽 →「沒有分頁檔」→「設定」→ 確定，重新開機
  5. 整理可用空間：defrag C: /X（舊硬碟要十幾分鐘）
  6. 再跑第 1 步的指令，到 6 以上就重跑模擬；還不夠就用「磁碟清理」清系統檔案後再重複第 5 步

轉換後 Windows 會被清掉，分頁檔、休眠不用改回來；只做模擬不轉的話，記得把分頁檔改回「自動管理」。

以上都不是：把畫面照片和桌面的結果檔、C:\deploy 裡的記錄檔一起交給技術人員。

6轉完想改回 Windows

可以，但原本的資料救不回來。

  1. 另一台電腦用微軟的 Media Creation Tool 做 Windows 安裝隨身碟（8GB 以上，隨身碟會被清空）
  2. 插上這台，開機按開機選單鍵（ASUS 常見 F8 或 Esc）選隨身碟
  3. 安裝類型選「自訂」，把 Flex 的分割區全部刪掉，裝在空出來的空間，約 30～60 分鐘
  4. Windows 10 以後出廠的電腦序號在主機板韌體裡，裝同一版本（家用版或專業版）連上網通常會自動啟用
