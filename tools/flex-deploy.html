ChromeOS Flex 遠端部署：完整使用說明

把 Windows 電腦轉成 ChromeOS Flex，從「什麼都沒裝的一台筆電」到「一整間教室」都在這裡。每一步都附畫面、你應該看到什麼、沒看到怎麼辦。

2026-10-02 圖解版｜搭配 intune-flex-deploy 工具｜依據：Google 官方 ChromeOS Flex Remote Deployment（FRD）說明頁與官方套件
⬇ 下載工具包（.zip） 解壓後雙擊「開始操作.bat」即可，不用另外裝任何東西

0這份說明怎麼讀

先看第一部弄懂觀念，然後依你的情況只讀需要的那一部。

你的情況讀哪裡
一台或幾台電腦，什麼都沒裝第二部：一鍵轉換檔（最常用）
一整間教室、幾十台第三部：大量派送
出問題了第四部第 20 章
已經轉好了，現在才要 CEU第五部

標記說明：

  • 實際畫面 我們實際操作截下來的畫面，或一鍵檔實際印出來的文字
  • 示意圖 Windows、Google 的畫面我們沒辦法直接擷取，照官方文件畫的，實際長相可能略有不同
怎麼做到「照做就成功」
  • 每一步都有檢查點：「你應該看到」跟畫面對得上才往下，對不上就照「沒看到的話」處理
  • 失敗不會毀掉電腦：Google 的 FRD 在動硬碟之前一定先跑完全部檢查，任何一項沒過就自己中止，Windows 照常能用
  • 每種新機型的第一台，先只跑模擬測試：一鍵檔預設就是「只測試」，只檢查、不動硬碟，跑完在桌面產生一個結果檔。你看過結果確認沒問題，才把設定改成正式轉換（第 6 章）
  • 誠實說明：真正的轉換我們還沒在實機跑過（截至 2026-10-02）。上面的「先測試」就是為了在客戶第一台上安全地補上這個驗證
整份說明最重要的一句話
轉換成功之後，整台電腦的 Windows 與所有資料都會被清空，救不回來。資料一定要先備份。
PART 1

先看懂

十分鐘弄懂整件事怎麼運作，後面每一步才知道自己在做什麼。

1一張圖看懂整件事

什麼都沒裝的 Windows 電腦，從頭到尾會經過這五站。

第 1 站Windows 電腦
什麼都沒裝
第 2 站對方雙擊一鍵檔
按「是」、輸入 Y

檢查＋模擬測試
第 4 站重新開機

第 5 站變成 ChromeOS Flex

沒填權杖（沒買 CEU）開機後自己選 Wi-Fi、用任何 Google 帳號登入，不受任何人管理

兩個名詞先記住

  • FRD：Google 官方的轉換工具，核心是一支 agent.exe。官方套件直接從 dl.google.com/cros-frd/frd-latest.zip 下載，不用申請、不用等回信
  • 一鍵轉換檔（一鍵轉換Flex.bat）：我們照 Google 官方範例腳本做的檔案，把「下載 FRD、寫設定、檢查、模擬、正式轉換」全部包在一起
為什麼不能「電腦連上網路就自動轉」
一台電腦只是連上網路，外面的人是叫不動它的，不然就是最嚴重的資安漏洞。所以每台電腦一定要被碰過一次：要嘛有人在那台上雙擊一鍵檔，要嘛之前就裝了 Intune、Action1 這類管理工具。這是 Windows 的安全設計，任何工具都一樣。

2權杖、CEU、Google 網域是什麼關係

這三個詞最容易搞混。重點：它們全部在客戶的 Google 帳號裡，跟 Windows 電腦一點關係都沒有。

客戶的 Google 網域（例如 xxx.edu.tw），在 Google 管理控制台管理
CEU 授權池客戶買的名額，例如 30 個。電腦註冊的那一刻扣 1 個
註冊權杖一串碼，代表「轉完請註冊到這個網域的這個組織單位」。不會過期、可重複使用
組織單位例如「三年甲班」。決定電腦轉完後套用哪些政策
↓ 權杖填進一鍵檔 → 電腦轉成 Flex → 第一次開機用權杖註冊 → 從授權池扣 1 個 CEU 綁給這台
常見問題答案
Windows 電腦上要先有 CEU 嗎？不用，也不可能。CEU 只能綁在已經是 ChromeOS 而且註冊好的裝置上。綁定是轉完註冊的那一刻自動發生的
「網域」是指什麼？指客戶的 Google 網域。跟 Windows 有沒有加入公司網域（Active Directory）無關
轉好之後能從電腦上查到權杖嗎？不能。權杖在客戶的管理控制台 → 裝置 → Chrome → 註冊權杖，那裡可以再複製
Wi-Fi 一定要給嗎？沒權杖時不用：官方說明 Wi-Fi 設定「需要先定義註冊權杖」才會生效，轉完在歡迎畫面自己選。有權杖時要給，或改插網路線

沒有 CEU 的話，轉完代表什麼（交件前要讓客戶知道）

  • 不會出現在 Google 管理控制台，不能統一派送政策、App、設定
  • 任何人都能用個人 Google 帳號登入
  • 遺失或被偷時無法遠端停用
  • 之後再買 CEU，沒辦法遠端補註冊，只能到現場一台一台處理（第五部）

3我該走哪條路

從上往下回答，第一個「是」就是你的路。

① 這批電腦已經被 Intune 管著，而且授權有效？
是路線 C：Intune 用原本的管理工具派送，不用碰電腦
② 只有一台或幾台，對方能幫忙雙擊一個檔案？
是一鍵轉換檔 最省事，第二部
③ 一整批，而且都在同一個地方（同一間教室、同一個網路）？
是路線 A：PsExec 每台準備一次，之後一次推全部
④ 一整批，分散在不同地方？
是路線 B：Action1 每台裝一次代理程式，之後雲端派送
都不是每台都沒人能操作、也連不進去：任何工具都做不到，只能安排人到現場

4接案時要問客戶的問題

  1. 電腦的廠牌和完整型號？幾台？ → 比對 Google 認證清單，狀態要是「通過認證」，不是就不接
  2. 你們的 Google 帳號有沒有買 CEU？剩幾個名額？ → 有就請管理員產生權杖；沒有要書面同意轉成未受管
  3. 轉完之後電腦在哪裡上網？ Wi-Fi（名稱、密碼，一般密碼型）或網路線
  4. 電腦有沒有被 Intune 管？都在同一個地方嗎？ → 決定走哪條路
  5. 是不是 S 模式？（Surface Go 出廠預設是）→ 第 19 章
  6. 資料備份了嗎？ → 請客戶書面確認
PART 2

一鍵轉換檔

單台或少量最省事的做法：對方雙擊、按「是」、輸入 Y，其他全部自動。

5事前確認

這五項全部打勾才往下。一鍵檔會自動檢查第 3～5 項，但先確認可以省下來回。

  • 型號在 Google 認證清單上，狀態是「通過認證」（只有這項一鍵檔沒辦法自動判斷）
  • 資料已經備份，客戶書面確認
  • Windows 10 或 11，不是 S 模式（設定 → 系統 → 啟用，版本名稱裡沒有「S 模式」）
  • C 槽可用空間 12GB 以上：官方寫 5GB，但同頁列出已知問題「部分裝置需要 9GB」，再加上下載套件約 3GB
  • 插著電源、網路連得上
開機模式 UEFI、磁碟 GPT
這兩項一鍵檔會自動檢查。Windows 11 的電腦一定符合；Windows 10 舊機不符合的話看第 18 章。

檔案在工具資料夾裡：一鍵轉換Flex.bat。要決定兩件事：這次只測試還是正式轉換、客戶有沒有 CEU。

先決定：只測試，還是正式轉換

情況$ONLY_TEST會發生什麼
這個型號第一次做$true（預設）只跑檢查與模擬測試，硬碟完全不動，跑完桌面出現結果檔
同型號已經測過、結果沒問題$false檢查、模擬，接著正式轉換，Windows 會被清空
建議：準備兩個檔案，用檔名區分
複製一份，一份保持 $true 改名叫 Flex-1測試.bat，另一份改成 $false 改名叫 Flex-2正式.bat。檔名可以隨便改，不影響功能。這樣就不會傳錯檔案。
為什麼預設是「只測試」
忘了改設定的話，最壞的結果只是多跑一次測試，不會在你還沒確認前就把客戶的電腦清空。

情況 A：沒有 CEU → 權杖、Wi-Fi 都不用填

只要照上面決定 $ONLY_TEST 就好。改法跟下面步驟 3 一樣，用記事本開啟、改最後一行。

情況 B：有 CEU → 先拿權杖，再填設定

步驟 1：請客戶的 Google 管理員產生權杖

一串像 12345678-90ab-cdef-1234-567890abcdef 的權杖，以及你選好的組織單位
管理員帳號沒有 Chrome 管理權限，或客戶根本沒有買 CEU。請客戶確認授權（管理控制台 → 帳單 → 訂閱）

步驟 2：問清楚轉完之後怎麼上網

  • Wi-Fi：要名稱和密碼，一般密碼型（WPA／WPA2 個人）。要登入帳號才能上網的企業型 Wi-Fi 不適用
  • 網路線：什麼都不用問，Wi-Fi 兩行留空，一鍵檔會自動改寫成官方的有線網路設定

步驟 3：用記事本填設定

在 一鍵轉換Flex.bat 上按右鍵 →「以記事本開啟」（或「編輯」），往下捲到「設定」那段：

有 CEU、用 Wi-Fi
$ENROLLMENT_TOKEN = '貼上權杖'
$WIFI_SSID = 'Wi-Fi名稱'
$WIFI_PASSWORD = 'Wi-Fi密碼'
有 CEU、用網路線
$ENROLLMENT_TOKEN = '貼上權杖'
$WIFI_SSID = ''
$WIFI_PASSWORD = ''
測試過、要正式轉換時（不管有沒有 CEU）
$ONLY_TEST = $false
三個容易出錯的地方
  • Wi-Fi 名稱或密碼本身有單引號 '，要寫成兩個 ''。中文、雙引號、反斜線都沒問題（2026-10-02 實測過）
  • 存檔時「編碼」保持記事本預設的 UTF-8，不要改成 ANSI，不然中文 Wi-Fi 名稱會壞掉
  • 檔案裡有權杖，只能私下傳，不要放公開連結

7把檔案交給對方

  • 推薦：Google 雲端硬碟連結（共用給對方的帳號，不要設成知道連結的人都能看）
  • 不要用 Gmail 附件：Gmail 會擋 .bat 檔，壓成 zip 也會被擋
  • 隨身碟也可以，複製到對方桌面再執行

附上一句話給對方就好：

  • 只測試的檔案：「插上電源，雙擊這個檔案，跳出視窗按『是』，看到要輸入的地方打 Y 按 Enter。跑完桌面會多一個『Flex結果』開頭的檔案，傳回來給我。」
  • 正式轉換的檔案：「資料備份好、插上電源，雙擊這個檔案，跳出視窗按『是』，看到要輸入的地方打 Y 按 Enter，之後電腦會自己重開機，不要關機。」

結果檔裡只有記錄，沒有權杖和 Wi-Fi 密碼，對方用 Gmail 附件或 LINE 傳回來都可以。

8對方要按的三個地方

整個過程對方只需要做這三件事，順序如下。

第 1 個：如果跳出「Windows 已保護您的電腦」

從網路下載的檔案，Windows 有時會先跳這個藍色視窗。不一定會出現，出現的話照下圖按兩下：

第 2 個：「您要允許此 App 變更您的裝置嗎？」按「是」

按「是」之後跳出一個黑色視窗，最上面寫著「把這台電腦轉換成 ChromeOS Flex」
按了「否」或視窗沒出現：重新雙擊一次檔案

第 3 個：看完說明，輸入 Y 按 Enter

只測試和正式轉換，開頭的畫面不一樣，對方一看就知道是哪一種：

============================================== 把這台電腦轉換成 ChromeOS Flex ============================================== 這次只做模擬測試：只檢查這台電腦能不能轉，不會改動任何東西，Windows 照常可以用。 跑完會在桌面產生一個結果檔，請傳給技術人員。 這次不註冊：轉完是一般的 ChromeOS Flex，開機後在歡迎畫面自己選 Wi-Fi、登入 Google 帳號。 要開始測試，請輸入 Y 再按 Enter: Y
實際畫面 只測試（$ONLY_TEST = $true），綠字開頭
============================================== 把這台電腦轉換成 ChromeOS Flex ============================================== 轉換完成後，這台電腦的 Windows 和裡面所有資料都會被清空，無法復原。 這次不註冊：轉完是一般的 ChromeOS Flex，開機後在歡迎畫面自己選 Wi-Fi、登入 Google 帳號。 資料都備份好、確定要繼續，請輸入 Y 再按 Enter: Y
實際畫面 正式轉換（$ONLY_TEST = $false），紅字警告。兩段都是沒填權杖的版本；有填權杖的話，「這次不註冊」那句會變成「轉完會自動註冊到貴單位的 Google 管理控制台」

在你的電腦操作工具

14路線 B：Action1（分散各地） 未實測

21轉完才買 CEU：只能到現場

CEU 的遠端大量註冊，只有一個時間點做得到：還是 Windows 的時候，用一鍵檔或 FRD 帶權杖轉換。

還是 Windows（可以遠端）一鍵檔或管理工具帶權杖 → 轉完自動註冊、綁 CEU
已經是未受管 Flex（只能現場）沒有任何遠端管道；Flex 不支援零接觸註冊與強制重新註冊（官方）
註冊之後（又可以遠端）政策、App、設定都從管理控制台遠端派送

已經轉好的機器，三種補救

做法現場要做的會不會清資料適合
A. 手動註冊登入畫面（還沒有人登入前）按 Ctrl+Alt+E，輸入管理員或被允許註冊的帳號沒人登入過不會；有人登入過要先 Powerwash（Ctrl+Alt+Shift+R），會清空台數少
B. 封權杖的 USB 重灌每台插隨身碟開機安裝，第一次開機自動註冊會台數多
C. 封權杖的映像檔走網路開機（PXE）每台設定從網路開機會有 IT 人員的大型場域

B、C 用 Google 的 cros-flex-tools 套件裡的 package_flex_image 把權杖封進映像檔，需要 Debian／Ubuntu 環境（WSL 也可以）、35GB 空間。詳見官方 Automatically enroll ChromeOS Flex devices。未實測

結論
接案第一句就問「你們的 Google 帳號有沒有買 CEU」。有的話，第一次轉換就把權杖填進去，一次做完。

23名詞解釋

ChromeOS Flex
Google 給一般 PC、Mac 用的免費 ChromeOS，裝上後用起來跟 Chromebook 差不多
FRD（Flex Remote Deployment）
Google 官方的遠端轉換工具，在 Windows 上執行 agent.exe 就能把整台轉成 Flex。直接下載，不用申請
一鍵轉換檔
我們照官方範例腳本做的 一鍵轉換Flex.bat，對方雙擊就自動下載 FRD、檢查、模擬；設定成正式轉換時才會接著轉換
CEU（Chrome Education Upgrade）
買在客戶 Google 網域裡的授權，裝置註冊時扣一個，之後才能集中管理。企業版叫 Chrome Enterprise Upgrade
註冊權杖
客戶管理控制台產生的一串碼，綁在組織單位上，告訴轉好的電腦要註冊到哪裡。不會過期、可重複使用，屬於機密
授權池
客戶買好、還沒用掉的 CEU 名額
未受管
沒有註冊進任何組織的 ChromeOS 裝置，等於個人用的機器
Google 網域
學校或公司的 Google 帳號系統，例如 xxx.edu.tw。跟 Windows 的網域（Active Directory）無關
InstallStarted
官方記錄事件：所有檢查通過，開始改動硬碟。正式轉換有沒有真的開始，看這個
InstallSkipped
官方記錄事件：模擬結束，或檢查沒過、部署中止。不能單看它判斷成功
dry_run（模擬測試）
FRD 只做檢查、不動硬碟的模式
$ONLY_TEST（只測試）
一鍵檔的設定。$true（預設）只跑到模擬測試就停並產生結果檔；$false 才會接著正式轉換
結果檔
一鍵檔結束或停止時放在桌面的 Flex結果-電腦名稱-日期時間.zip，裡面是記錄檔，不含權杖與 Wi-Fi 密碼
UEFI／Legacy BIOS
開機時先跑的韌體，新的叫 UEFI。FRD 只支援 UEFI
GPT／MBR
磁碟分割表格式，UEFI 配 GPT
S 模式
Windows 的限制模式，只能裝 Microsoft Store 的 App
TPM
主機板上的安全晶片。部分機型轉換前一定要清除
ONC
Google 的網路設定格式，用來預先寫入 Wi-Fi 或有線網路設定。需要有權杖才生效
PsExec
微軟的免費工具，從一台電腦遠端在另一台執行程式，需要對方的管理員帳密
Action1
雲端遠端管理平台，每台裝代理程式後可從網頁派送指令，前 200 台免費
Intune
微軟的雲端裝置管理服務，要另外付費
LocalAccountTokenFilterPolicy
Windows 登錄設定，設成 1 才允許非內建 Administrator 的本機管理員帳號從遠端管理
AP 隔離
Wi-Fi 基地台的設定，開了之後同一個 Wi-Fi 的裝置彼此連不到
Powerwash
ChromeOS 的恢復原廠設定
