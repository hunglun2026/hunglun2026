第 1 步：建一份新的試算表

資料會存在這份試算表裡。請用您自己的 Google 帳號。

📄 打開新的空白試算表（新分頁）
  1. 試算表打開後，左上角「未命名的試算表」點一下，改名成「班級秩序登記資料庫」，按 Enter。
  2. 這個分頁先留著，做完回來按「下一步」。

第 2 步：貼上後端程式碼

後端是住在試算表裡的小程式，負責收資料。

  1. 在試算表上方選單點「擴充功能」→「Apps Script」，會開一個新分頁。
  2. 在編輯器裡按 Ctrl+A 全選，再按 Delete 刪掉原本的文字。
  3. 按下面的大按鈕複製程式碼。
  4. 回到編輯器按 Ctrl+V 貼上，再按 Ctrl+S 儲存（跳出專案名稱就填「早修登記後端」）。
按鈕沒反應？展開程式碼，自己全選複製

第 3 步：部署成網頁應用程式

  1. Apps Script 右上角藍色「部署」→「新增部署作業」。
  2. 點「選取類型」旁的齒輪，選「網頁應用程式」。
  3. 「執行身分」選我；「誰可以存取」選所有人。
  4. 按「部署」。第一次會要求授權：「授權存取」→ 選您的帳號 → 若出現「Google 尚未驗證這個應用程式」，點左下「進階」→「前往（專案名稱）（不安全）」→「允許」。
  5. 出現「網頁應用程式網址」後，按它下面的「複製」。
這是您自己剛建的程式，只會讀寫您這一份試算表，授權可以放心。
如果「誰可以存取」找不到「所有人」，通常是學校的 Google 帳號被網管限制。請改用個人 Gmail 帳號從第 1 步重做，或請學校資訊組協助。

第 4 步：貼上網址並測試連線

把第 3 步複製的網址（以 https://script.google.com/ 開頭、/exec 結尾）貼在下面。

第 5 步：把網址鎖進這個畫面

Canvas 關掉再打開，會忘記剛貼的網址（Canvas 的限制，不是壞掉）。所以要把網址「寫進」這個 Canvas 的程式碼，之後風紀打開才會自動連線。只要做一次。

✅ 網址已經鎖進這個畫面了，這一步完成。請按「下一步」。

做法：請 Gemini 幫您改這一行（最簡單）

  1. 按下面的大按鈕，複製「要貼給 Gemini 的那句話」。
  2. 貼到這個 Canvas 下方的對話輸入框（「問問 Gemini」那一格），按送出。
  3. 等約半分鐘，Gemini 說改好了、畫面重新載入，就完成。
  4. 重新載入後，按右上角「導師後台」，第一次會請您設定導師密碼，就大功告成。
如果畫面出現「發生錯誤」和「修正錯誤」按鈕，請不要按。那個按鈕會叫 Gemini 自己改程式，可能改壞。
找不到對話輸入框，或 Gemini 沒改成功？展開看另外兩種做法
做法二：自己改程式碼
  1. 按下面的按鈕，複製要貼的那一行。
  2. 到 Canvas 右上角，把「預覽」切到「程式碼」。
  3. 按 Ctrl+F 搜尋 EMBEDDED_GAS_URL，第一個結果就是程式最上面那一行：const EMBEDDED_GAS_URL = "";
  4. 把那一整行選起來，按 Ctrl+V 貼上取代，再切回「預覽」。

第 6 步：把登記連結傳給風紀

這個連結已經帶著您的雲端網址。風紀第一次打開時會問「是導師傳給您的嗎？」，按確定，這台裝置就會記住，之後直接用。請先確定第 5 步的導師密碼設好了，再傳。

用 LINE 傳給風紀即可。風紀換一台裝置，要再打開一次這個連結。

第 6 步：設定導師密碼

設好密碼後，把這個 Canvas 的分享連結（Canvas 右上角的分享按鈕）用 LINE 傳給風紀。風紀打開就是登記畫面，不用貼任何東西。

登記項目與規則

每位老師的班規不同，這裡可以改成您自己的。儲存後，風紀馬上看到新的項目；統計表和試算表的欄位也會跟著變。

已經登記過資料之後，請只修改文字，不要調整順序或刪除項目，否則舊資料的項目會對不上。要增加項目，請加在最後面。

次數門檻在「每月結算」頁上方設定。

名冊設定

名冊每行一位，格式「座號,姓名」，例如 01,王小明。改完按儲存，會同步上傳試算表。

備份與測試資料

建議每個月匯出一次備份存在自己的電腦。
