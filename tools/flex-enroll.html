Flex 權杖版產生器

填入學校的註冊權杖，產生「轉完自動註冊、套用 CEU」的一鍵轉換檔。

開始之前

  1. 學校網域要有 CEU 授權（管理控制台 →「帳單」→「訂閱」），數量要夠這次的台數
  2. 管理控制台先建好放 Flex 的機構單位，在那裡把時區設成 Asia/Taipei、語言與注音設好，轉完開機就會是對的
  3. 註冊權杖要綁在那個機構單位（管理控制台 →「裝置」→「Chrome」→ 註冊權杖）

填寫設定

只支援一般密碼型（WPA／WPA2 個人）。要輸入帳號才能登入的企業型 Wi-Fi 請改插網路線。

下載之後

  1. 先從 ChromeOS Flex 下載 下載整包（只要一次），解壓縮得到 flex 資料夾
  2. 把這裡產生的 zip 解壓縮，裡面三個 bat 複製到 flex 資料夾，取代舊的
  3. 每台照順序：空間不夠先跑 清出C槽空間.bat → 一鍵轉換Flex-模擬.bat 看到 5/5 → 一鍵轉換Flex-正式.bat
  4. 每種型號先試 1 台，確認轉完畫面寫「這部裝置由學校網域管理」、時間正確，再做其他台

產生出來的檔案裡有註冊權杖和 Wi-Fi 密碼（明文），只交給要操作的人，不要放到公開的地方。權杖與密碼只在你的瀏覽器裡處理，不會送到我們的伺服器。
