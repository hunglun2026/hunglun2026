用 Intune 派送 ChromeOS Flex

簡易版：照順序做就好。完整說明看下方連結的手冊。

正式轉換會清空電腦Windows 和所有檔案都會消失，救不回來。開工前要有客戶的書面同意。
Intune 送的不是映像檔Intune 只送一個約 1GB 的安裝包（內含遙控程式和你的權杖）。Flex 映像檔是每台電腦裝好後，自己連網從 Google 下載，所以電腦要連網、要插電。
  1. 備權杖
  2. 產生安裝包
  3. 建兩個 App
  4. 試點
  5. 整批推正式版
  6. 確認註冊

1備好有 CEU 的權杖

  1. Google 管理控制台 → 裝置 → Chrome → 註冊憑證 → 註冊 → 非 ChromeOS 裝置 → 自動註冊。
  2. 選該校的機構單位，權杖類型選 ChromeOS Enterprise 或 Education 升級版，新增權杖並複製。
授權不夠會註冊失敗權杖綁的授權（CEU）用完時，電腦會轉成功但註冊不上。先確認數量夠。

2替學校產生兩個安裝包

  1. 下載下方的「Flex 部署工具包」，在 zip 上按右鍵「全部解壓縮」，雙擊 產生學校安裝包.bat（不用另外裝任何東西）。
  2. 第一次先輸入 A，依序貼學校名稱、權杖、Wi-Fi 名稱、Wi-Fi 密碼。權杖格式不對，程式會直接擋下。
  3. 回到清單後輸入該校的編號，再輸入 Y，程式會連續做出模擬版和正式版，各約 1GB，要等幾分鐘。
  4. 成品在 output\學校名稱\：兩個 .intunewin 檔和一份「上傳清單」，下一步建 App 照著抄。換學校就重複這一步，每間學校的檔案各放各的資料夾。
Wi-Fi 一定要打對打錯的話，轉換會成功，但電腦都註冊不上。
安裝包內含權杖只放在自己的電腦和 Intune，不要放雲端分享、不要寄出去。

3在 Intune 建兩個 Win32 App

應用程式 → Windows → 新增 → Windows 應用程式 (Win32)，上傳安裝包。模擬版、正式版各建一個，只要改下面這幾格，其他用預設：

若學校的 Surface 在 S 模式，要先用「組態 → 範本 → 版本升級和模式切換」退出 S 模式，並指派給要轉的電腦。

4試點 1 到 3 台

  1. 模擬版指派給「裝置群組」，類型選 Required（不要指派給使用者，才不用等人登入）。
  2. 在那幾台按 Intune「同步」，或直接重開機。不手動觸發的話可能要等好幾個小時。
  3. Intune 顯示 0 就是通過。接著指派正式版給同樣幾台，再同步。
  4. 顯示 1641 或一直「安裝中」都正常，電腦正在重開機轉換。
  5. 轉完確認這幾台有註冊成功（步驟 6），才往下。

5其他電腦直接推正式版

  • 不用再跑模擬版，正式版安裝時會先自己檢查，沒過不會動硬碟。
  • 一次一批，每批推完按同步，再看結果。
  • 電腦要插電、開機、連網。建議打開「傳遞最佳化」，同網段的電腦會互相分享安裝包，比每台都從雲端下載快。

6確認註冊成功

Google 管理控制台 → 裝置 → Chrome → 裝置，用序號找到電腦，看它在不在該校的機構單位，授權數有沒有減少。
