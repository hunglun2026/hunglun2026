1先弄懂：Flex 的「零接觸」怎麼做到

零接觸的意思是：事先把「這台屬於哪個學校」記好，現場不用設定，電腦連上網就自己註冊。Chromebook 和 Flex 都做得到，差在「事先記在哪裡」。

Chromebook 零接觸Flex（這套做法）
「屬於誰」記在哪Google 伺服器（用序號事先登記）電腦自己身上（轉換時寫入註冊權杖）
怎麼記進去零接觸工具送序號、型號給 Google一鍵轉換檔帶著權杖執行
開機連網後問 Google → 自動註冊用權杖 → 自動註冊
CEU註冊那刻扣 1 個註冊那刻扣 1 個
Flex 不能用零接觸工具：Google 官方寫明零接觸註冊不相容 ChromeOS Flex。PC 的韌體不會去問 Google，序號登記了也沒用。

CEU 和權杖不一樣

  • CEU（控制台裡叫「ChromeOS 升級版」）：授權名額，像座位，一台佔一個
  • 註冊權杖：像學校的報到密碼，綁在一個組織單位上，整個單位的電腦共用同一組
30 台用同一組權杖轉換→每台開機報到→Google 自動各分 1 個 CEU→30 個 CEU 用完

所以同一個單位、同一組網路的電腦，一鍵轉換檔內容完全一樣，不用每台準備不同的東西。CEU 不夠時，多出來的電腦會註冊失敗。

2要準備什麼、不用準備什麼

零接觸工具要填的欄位，Flex 大部分都不用：

欄位Flex 要不要說明
序號（SN）選填方便之後在控制台對照是哪一台
硬體型號（Model）不用電腦報到時自己回報；一鍵檔模擬時會自動比對 Google 認證清單
預先配置代碼不用那是零接觸給廠商用的。Flex 要的是下面的「註冊權杖」，兩個不能混用
認證裝置 ID（ADID）不用Chromebook 出廠燒在機器裡的身分，PC 沒有
客戶 ID／網域不用權杖本身就代表哪個網域、哪個單位
Google Device ID不用註冊完 Google 自動產生
註冊權杖要第 5 步產生，一個單位一組
電腦名稱要Windows 的電腦名稱（設定 → 系統 → 關於 → 裝置名稱），各台結果檔靠它對應
網路要網路線，或 Wi-Fi 名稱＋密碼（一般密碼型）。Flex 要全自動就得事先寫好網路
每台電腦還要符合：Windows 10／11、UEFI 開機、C 槽能縮出 5GB 以上、沒有還原卡，型號最好在 Google 認證清單上。一鍵檔模擬時會自動檢查。

3控制台：確認 CEU 夠不夠

用學校（客戶）的超級管理員登入 admin.google.com。

先看首頁「網域」卡片的主網域是不是你要的那個。同一家單位可能有好幾個 Google 帳號，權杖建在哪個網域，電腦就註冊到哪個網域。
  1. 左邊 帳單 → 訂閱：找 ChromeOS 升級版，「授權」欄是總共買了幾個（例如 30 位升級）
  2. 看用掉幾個：裝置 → Chrome → 裝置，左邊選最上層網域，數清單上幾台（每台佔 1 個）。右上角 查看升級項目 也看得到

剩餘數量 ≥ 這次要轉的台數才往下。帳單 → 授權設定只管使用者授權，看不到 CEU。

4控制台：建組織單位

權杖綁在組織單位上，電腦註冊後會進這個單位、套這個單位的政策。

  1. 左邊 目錄 → 組織單位
  2. 滑鼠移到最上層網域那一列，按右邊的 ＋（或上方 建立組織單位）
  3. 名稱例如 Flex-三年甲班，上層選要放的位置，按建立
第一次做建議先建一個測試單位（例如 Flex測試），一台通過再建正式單位。

5控制台：產生註冊權杖

  1. 裝置 → Chrome → 裝置，右上角按 註冊裝置
  2. 步驟 1「您想註冊哪種裝置？」選右邊 非 ChromeOS 裝置 (採用 ChromeOS Flex) → 下一步
  3. 步驟 2「您想如何註冊？」選中間 自動註冊 (USB 安裝程式) → 開始
  4. 按 建立 USB 安裝程式
  5. 「安裝封裝工具」那頁是 Linux 指令，不用理它，直接按 下一步
  6. 「選取組織單位」選第 4 步建的單位，確認下方「已選取」對了 → 下一步
  7. 「選擇權杖」：保持 新增權杖，升級類型選 ChromeOS Enterprise 升級版或 ChromeOS Education 升級版（Kiosk 是資訊站用的，不要選），註解填用途（例如「三年甲班 Flex」）→ 設定
  8. 出現「已成功建立新權杖」，按權杖右邊的複製圖示
  9. 左上角 X 關掉。後面「建立映像檔、USB」是 Google 自己的 USB 做法，我們用一鍵轉換檔，不需要
畫面寫要準備 USB 隨身碟、Debian/Ubuntu，那是 Google USB 做法用的，我們只拿權杖。關掉精靈不會刪權杖，之後在 裝置 → Chrome → 註冊憑證 選單位就查得到、可以再複製。
權杖等於進入學校網域的通行證：不要貼在公開地方、截圖要遮。外流就在同一頁按權杖下方的藍字按鈕停用，再產生新的。

6控制台：先設好政策

電腦註冊進單位就會自動套用，事先設好，轉完開機就是對的。選好單位後到 裝置 → Chrome → 設定：

分頁設定建議
裝置時區Asia/Taipei（沒設會顯示美國時間）
裝置登入限制只允許學校網域帳號
裝置訪客模式停用
使用者與瀏覽器語言、允許的輸入法繁體中文、加注音（沒設只有英文鍵盤）
應用程式和擴充功能強制安裝學校要用的 App
Flex 不支援「強制重新註冊」：有人把 Flex 恢復原廠（Powerwash），它就變回未受管，要到現場重新註冊。登入限制設好、學生不要給管理員權限。

7大量部署系統：填表、產生

開 Flex 大量部署系統（跟零接觸工具一樣，一列一台、可以「填滿」）：

  1. 按 10 或 99 新增列數，每列填一台的電腦名稱（Windows 的電腦名稱）。台數多可以用 匯入 Excel 整批貼
  2. 第一列貼上權杖，按權杖欄的 填滿，全部套用
  3. 第一列選網路（網路線或 Wi-Fi），用 Wi-Fi 再填名稱、密碼，各按一次 填滿
  4. 按 產生全部一鍵轉換檔，下載 zip：一台一個資料夾，裡面三個檔（模擬、正式、清出C槽空間），外加 Flex清冊.xlsx
  5. 按 匯出清冊 存一份 Excel 備份（不含權杖和密碼）
權杖和 Wi-Fi 密碼只在你的瀏覽器裡處理，不會送到伺服器，重新整理要重填。產生出來的 bat 裡是明文，只交給操作的人。

8到現場：模擬、正式

  1. 從 ChromeOS Flex 下載拿整包，解壓成 flex 資料夾
  2. 把那台電腦資料夾裡的三個 bat 放進 flex 資料夾
  3. 雙擊 模擬 那個，按「是」。跑完桌面出現 Flex結果-電腦名稱-時間.zip，畫面寫 5/5 通過才往下
  4. 空間不足就先雙擊 清出C槽空間（可能會重開一次），再模擬一次
  5. 雙擊 正式 那個，輸入 Y。電腦會自己重開機開始安裝，Windows 和資料會被清空
每個新型號，先 1 台跑完正式、驗收過，再推其他台。資料一定要先備份。

台數多不想一台台雙擊：已經有 Intune、或同一個網路、或裝了 Action1 的，可以用遠端派送，見 Flex 遠端部署手冊第三部。

9驗收：怎麼確認自動註冊成功

  1. 電腦裝好、開機到歡迎畫面，網路線插著（或 Wi-Fi 在範圍內），不用按任何東西
  2. 畫面出現「由 學校網域 管理」就是自動註冊成功
  3. 控制台 裝置 → Chrome → 裝置，選那個單位，看到這台（可用序號找），CEU 少 1 個
  4. 把各台的結果 zip 拖進大量部署系統，狀態自動更新；確認註冊的可以手動改成「已註冊完成」
截至 2026-10-07，「一鍵轉換檔帶權杖 → 開機自動註冊」這一段還沒在實機驗證過（轉換本身已在 ASUS SD310 實機成功）。第一台驗收時請特別確認這一步，有出入回報技術人員。
登入後在網址列打 chrome://policy，看得到第 6 步設的政策，就代表政策也下來了。

10很多學校時怎麼分

每校有自己的 Google 網域全部在同一個網域（一校一個單位）
CEU各校自己買，買在哪個網域只能用在那個網域同一池共用
權杖各校管理員各自產生每校的單位各產生一組
做法一次做一間學校：填該校電腦、貼該校權杖按填滿、產生；清空後換下一校。也可以先在 Excel 把各校清冊整理好（權杖欄直接填好），一校匯入一次
開工前每校先收齊：台數、Windows 電腦名稱清單、權杖、網路（Wi-Fi 名稱密碼或網路線）、CEU 剩幾個。每校先 1 台跑模擬，通過再推全校。

11出問題怎麼辦

狀況原因怎麼做
開機沒有自動註冊，停在網路畫面網路沒通，或 Wi-Fi 名稱密碼錯插網路線；或在畫面上手動選 Wi-Fi，連上後照設計會繼續自動註冊（還沒實測）
註冊失敗，說授權不足CEU 用完了補買，或在控制台把不用的裝置「解除佈建」退回 CEU
註冊到別的網域權杖拿錯網域到該網域控制台解除佈建，Powerwash 後重新註冊
已經轉成 Flex 但沒帶權杖（未受管）轉換時沒填權杖到現場：登入畫面（沒人登入過）按 Ctrl+Alt+E，用管理員帳號註冊；有人登入過要先 Powerwash
Ctrl+Alt+Shift+R（Powerwash）沒反應沒登出；或裝置受管，使用者不能自己洗先登出、在登入畫面按；受管的要先在控制台解除佈建
權杖外流控制台 裝置 → Chrome → 註冊憑證 選單位，把舊權杖停用，產生新的、重新產生一鍵檔
模擬沒過空間、UEFI、TPM、還原卡等看說明欄的原因，照 手冊第四部處理
測試機用完要退 CEU：控制台對那台按「解除佈建」（不是「停用」，停用不會退授權）。
