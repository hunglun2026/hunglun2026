執行記錄

怎麼用
  1. 先在管理控制台：確認 CEU 授權夠、建好放 Flex 的機構單位並設時區 Asia/Taipei、產生綁該單位的註冊權杖
  2. 一台一列。電腦名稱要填 Windows 的電腦名稱（設定 → 系統 → 關於），結果檔靠它對應；也可以先「匯入 Excel」整批貼進來
  3. 按「產生全部一鍵轉換檔」，下載的 zip 裡一台一個資料夾。到那台時，把它資料夾裡的三個 bat 放進整包的 flex 資料夾（整包在 ChromeOS Flex 下載）
  4. 每台跑完模擬或正式，桌面的結果檔收回來拖進上面的框，狀態會自動更新
權杖與 Wi-Fi 密碼只在這個瀏覽器裡處理，不會送到伺服器，也不會存起來（重新整理要重填）；產出的 bat 裡是明文，只交給操作的人。 完整說明：Flex 遠端部署手冊
