Flex USB 換學校說明

一支 USB 通用多間學校，換學校只改 USB 裡的註冊權杖，約 0.1 秒，不用重刷。只支援 Windows 10／11。

⬇ 下載 Flex 隨身碟工具包（約 1.5GB） 解壓縮後雙擊「換學校.bat」，裡面有做隨身碟、換權杖與使用說明
快速使用 新增學校完整流程 時區設定 後台產權杖 出狀況怎麼辦 手動清空隨身碟 注意事項

快速使用（從一支空的隨身碟開始）

  1. 整個資料夾先完整解壓縮到一般資料夾，不要在 zip 裡直接雙擊。資料夾裡的「映像檔」不能刪，裡面是做隨身碟要用的 Flex 映像。
  2. 雙擊 換學校.bat（打不開就雙擊 Start-GUI.bat），Windows 詢問視窗按「是」。
  3. 做 Flex 隨身碟（每支新隨身碟做一次）：插上 16GB 以上的隨身碟，在視窗第一欄選到它（核對容量），按右上角「做 Flex 隨身碟」。裡面的資料會全部清掉，約 5 到 15 分鐘，過程中不要拔掉。跳出「做好了」就完成，不需要另外格式化或用其他軟體。
  4. 按「新增學校」，打學校名稱，貼後台產的自動註冊權杖（小寫 UUID，36 個字元）。後台怎麼產見下面「後台產權杖」。
  5. 在清單選學校，按綠色大按鈕「換成選取的學校」（雙擊那一列也可以），約 0.1 秒。
  6. 記錄欄出現「完成：已換成……讀回相符」，就能拔隨身碟去裝電腦。之後換別間學校，只要重做第 5 步，不用重做隨身碟。
  • 視窗上方的狀態列會寫這支隨身碟現在綁哪間學校；清單裡有「★ 這支 USB 現在綁這間學校」。
  • 視窗開不起來，改用 換學校-文字版.bat（黑底文字選單，只能換權杖，不能做隨身碟）。
  • 已經用 Chrome 擴充功能「裝置復原公用程式」做好的 Flex 隨身碟也能用：插上後按「第一次準備這支 USB」，再換學校。
  • 插上做好的隨身碟，Windows 可能不顯示磁碟代號，或跳「需要格式化」，一律按取消，不要格式化。

新增一間學校的完整流程

  1. 後台建機構單位：目錄 → 機構單位 → 建立新單位，名稱例如 2026-1104-flex測試。
  2. 後台產註冊權杖：照下面「後台產權杖」，選這個新單位，複製那串權杖。
  3. 後台設時區（每個單位一次）：照下面「時區設定」。
  4. 換權杖：開這個視窗，按「新增學校」貼上名稱和權杖，選那一列，按綠色大按鈕。
  5. 裝機：用這支 USB 開機安裝。裝完後台「裝置 → Chrome → 裝置」會在該單位底下看到這台，狀態「已佈建」。
  6. 驗證：登入畫面確認時區是台灣；之後把 USB 插回來，視窗上方狀態仍顯示那間學校，沒有「設定檔被系統清除」。
同一台電腦要重裝測試：先在後台把那台「取消佈建」，授權會還回來，再重裝。 測完的清理：把測試裝置取消佈建；單位與權杖可以留著下次用，不想用了就到後台「註冊憑證」取消那組權杖。

時區設定（每個機構單位做一次）

沒指定時，ChromeOS 靠 IP 位址猜時區，有些網路會猜錯，所以裝完有時是台灣、有時不是。在單位的政策裡固定成台灣，就不會再猜。

一、進到設定頁

  1. 後台左邊選單：裝置 → Chrome → 設定。
  2. 上方分頁點 「裝置設定」（不是預設的「使用者與瀏覽器設定」）。
  3. 左邊機構單位清單，點你要設的單位。一定要先選對單位，設定才會存在那個單位。

二、找到時區

  1. 點「搜尋或新增篩選器」，輸入 時區。
  2. 往下捲到 「其他設定」 區塊，點 「時區」 那一列。

三、改兩個欄位並儲存

欄位改成
系統時區Asia/Taipei - 台北標準時間 GMT+08:00（原本是「沿用裝置目前的時區」）
自動偵測系統時區一律不自動偵測時區（原本是「讓使用者決定」）

最後按左下角藍色 「儲存」。

四、確認有存成功

  1. 回到清單，「時區」那列的沿用來源，應該從上層網域變成這個單位，或顯示「已在機構內採行」。
  2. 再點進去，兩個欄位還是上面那兩個值。
改在哪一層：設在上層單位，底下的學校單位會繼承；但上層會影響所有單位，包括別的學校。 先在測試單位驗證沒問題，再決定要不要往上放。沒設在上層的話，每新增一個學校單位都要重做一次，漏掉就回到「靠 IP 猜時區」。
實機驗證：取消佈建測試機，用 USB 重裝，裝完到登入畫面看時區是不是台灣。錯誤不是每次都發生，建議多裝幾次。 註冊完成之前（安裝中、第一次歡迎畫面），政策還沒下載，這段時間的時區可能還是猜的；這點沒有官方文件佐證，以登入畫面看到的為準。

後台產註冊權杖

  1. 後台 裝置 → Chrome → 註冊憑證，按「註冊」。
  2. 選「非 ChromeOS 裝置」→「自動註冊（USB 安裝程式）」。
  3. 選該校的機構單位。
  4. 新增權杖（授權類型：ChromeOS Enterprise 或 Education 升級版）。
  5. 複製畫面上那串 36 字元權杖，停在那頁不用往下。
權杖等同註冊憑證：拿到的人可以把電腦註冊進該校網域並用掉授權。請只放在自己的雲端硬碟，不要分享連結； 不用了就到後台「註冊憑證」取消那組權杖。學校清單（學校清單.json）內含權杖，不要放進公開的地方。

出狀況怎麼辦

狀況處理
雙擊後黑視窗寫 [ERROR]照它說的做。常見三種：沒解壓縮完整；這台電腦把 PowerShell 鎖住（受限語言模式）；腳本被群組原則或資安軟體擋掉。後兩種這台電腦就沒辦法用，換一台。
沒有視窗、也沒有訊息多半是 Windows 詢問視窗被取消。重新雙擊，按「是」；要輸入密碼就用有系統管理員權限的帳號。
跳出錯誤對話框記錄也存在 %TEMP%\flex-swap-error.txt，把這個檔案或對話框內容給 Claude。
找不到 USB、表格怪怪的按視窗上的「診斷（複製資訊）」，貼給 Claude。內容只有電腦與磁碟基本資料，權杖只含前 8 碼。
寫入失敗，提示「存取被拒」多半是防毒軟體或群組原則擋住直接寫入磁碟（公司或學校管理的電腦常見），這台就不能用。
按「做 Flex 隨身碟」跳「找不到映像檔」資料夾裡的「映像檔」不見了，或沒完整解壓縮。把它放回工具資料夾裡，或在跳出的選檔視窗選 flex-image.img.gz。
做隨身碟時說「這支 USB 太小」或找不到 USB隨身碟要 16GB 以上，而且是外接的 USB，系統碟和內建硬碟工具一律不會列出。
做隨身碟說「讀回的內容不一樣」或「雜湊不符」「讀回不一樣」多半是隨身碟或 USB 孔有問題，換一支隨身碟、換個孔（用機身後面的孔，不要用延長線或集線器）再做。「雜湊不符」是映像檔下載不完整，重新下載映像檔。
按「第一次準備」被拒絕，說映像版本不認得Google 換了新版映像（公用程式永遠抓最新版）。在剛做好、還沒準備過的那支 USB 上，用系統管理員開 PowerShell 執行 進階\為新版映像產生補丁.ps1，它會唯讀取出那支 USB 的資料區、交給 WSL 裡的官方腳本產生補丁，存成 data\<版本>，之後視窗自動認得。需要 WSL（Ubuntu）與官方 package_flex_image，暫存槽要 8GB 以上；全程不寫入 USB。
做 USB 時，復原公用程式卡在 0%隨身碟上有舊分割區（別人用過的碟常見），跟容量無關。照下面「手動清空隨身碟」清掉再重做。
插上 USB，Windows 跳「需要格式化磁碟」一律按取消，千萬不要格式化。
視窗顯示「設定檔被系統清除，要重做 USB」Flex 從 USB 開機時偶爾會把 USB 的資料區重建，權杖檔就消失了（2026-11-03 遇過一次，原因不明；11-04 還原後連續裝機沒再發生）。這時換權杖會被擋下來，要把 USB 還原或重做，把畫面貼給 Claude。
裝完機時區不是台灣回後台看該單位的「時區」有沒有存成 Asia/Taipei，沒存就補存；存了還是錯，把機器序號與單位名稱給 Claude。

手動清空隨身碟（復原公用程式卡在 0% 時）

先按復原公用程式的「取消」並關掉它（它不能續跑，開著會佔住隨身碟）。清空會整顆刪除，不能復原，選錯碟會清到別顆，所以一定用容量認碟。

方法一：磁碟管理（不用打指令，建議）

  1. 對「開始」按右鍵 → 磁碟管理。
  2. 看下半部，找那顆隨身碟（標「卸除式」、容量跟你買的一樣，例如 32GB 約顯示 29.3GB）。不要選到電腦內建的硬碟（通常是最大、標系統或開機的那顆）。
  3. 在它右邊每個區塊上按右鍵 → 刪除磁碟區，直到整條變成黑色「未配置」。
  4. 回復原公用程式重新做。不用格式化，它會自己分割。

方法二：diskpart（幾行指令）

用系統管理員開 PowerShell 或命令提示字元，依序輸入：

diskpart
list disk
select disk 2
clean
exit

list disk 會列出所有碟，用容量認出隨身碟。select disk 後面的編號要換成你認出的那個，不要照抄 2，插拔後編號可能不同。

小心：選錯碟會清掉別顆，而且救不回來。電腦內建的硬碟容量通常是 256GB 以上，跟 16～64GB 的隨身碟差很多，看容量不會搞混。Windows 跳「需要格式化磁碟」時一律按取消。

注意事項

  • 需要系統管理員權限（用內建的 Windows PowerShell 5.1，不用裝任何東西）。
  • USB 要 16GB 以上。「做 Flex 隨身碟」用資料夾裡的映像，不需要上網下載；自己用復原公用程式做的碟也能用。工具認得的映像版本放在 data 資料夾（目前 16805.36.0、16836.30.0）；不認得的版本會停手、不會亂寫。
  • 只處理「16GB 以上、外接、非開機碟、非系統碟」的 USB；寫入前比對位置簽名，寫完讀回比對。
  • 放雲端硬碟用時：Google Drive 要把資料夾設成「離線可用」（或複製到電腦上）再執行；zip 被 Windows 擋，解壓縮前先在 zip 上按右鍵 → 內容 → 勾「解除封鎖」。
  • 官方文件沒有寫換權杖的方法，這是依官方腳本 package_flex_image 的原始碼推出來，已在實機驗證（2026-11-02 首次、2026-11-04 換單位重裝）。
